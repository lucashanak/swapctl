Parallel slots

currently {{ parallel_slots }}

Number of concurrent requests llama-server handles per model (continuous batching). Higher = more total throughput when serving multiple users or batched tests. KV cache is split across slots, so per-slot context = total ctx / slots. Changing this rebuilds the llama-swap config and restarts the service.

Sends multiple questions concurrently (faster but may give different results due to KV cache slot sharing). Off by default — sequential testing is more reliable.
