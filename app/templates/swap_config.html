Swap config

Controls how llama-swap keeps models in GPU memory and which can coexist. Changes restart llama-swap; on failure the previous config is auto-restored.

Models, priority & backend

Priority controls eviction order. Backend switches between HIP (stable ROCm), Vulkan, or Rock (TheRock nightly) per model.

Concurrent combinations

Auto-generated from model sizes and GPU budget. Models that fit together can stay loaded simultaneously.
