TTS — Text-to-Speech (Piper + XTTS-v2, via swapctl)

Public endpoints — no authentication required. Two engines available: Piper (fast, ONNX, ~0.3 s) and XTTS-v2 (neural, multilingual, ~3–8 s CPU). Select engine via voice prefix: xtts: routes to XTTS-v2, any other voice routes to Piper.

POST /api/v1/audio/speech

Synthesize text to audio. Body: {"voice": "...", "input": "...", "language": "auto", "response_format": "wav"}.

Piper voices (fast): see Voices page or GET /api/v1/audio/voices
XTTS-v2 (neural, multilingual): prefix voice with xtts: — e.g. xtts:default or xtts:default_en. Supports language: "auto" (auto-detects CS/EN from text). First request ~30 s (model load), subsequent ~3–8 s. CPU-only for now. 
curl -X POST {{ public_base }}/api/v1/audio/speech \
  -H 'Content-Type: application/json' \
  -d '{"voice":"{{ example_voice }}","input":"Ahoj, jak se máš?","model":"tts-1"}' \
  -o output.wav

# XTTS-v2 (neural, auto-detects Czech/English):
curl -X POST {{ public_base }}/api/v1/audio/speech \
  -H 'Content-Type: application/json' \
  -d '{"voice":"xtts:default","input":"Hello, jak se máš?","language":"auto","response_format":"mp3"}' \
  -o out.mp3

STT — Speech-to-Text (Whisper, via swapctl → llama-swap)

Public endpoints — no authentication required. Proxied to the llama-swap whisper-server backend.

POST /api/v1/audio/transcriptions

Transcribe audio file. Multipart form: file=@audio.wav and model=whisper-large-v3-turbo-q4-1. Returns {"text": "..."}.

curl -X POST {{ public_base }}/api/v1/audio/transcriptions \
  -F 'file=@recording.wav' \
  -F 'model=whisper-large-v3-turbo-q4-1'

OpenWebUI Integration Tips

Configure OpenWebUI to use this server for TTS and STT:

TTS
  • Admin Panel → Settings → Audio → TTS Engine: OpenAI (or "OpenAI Compatible" on newer builds)
  • API Base URL: {{ public_base }}/api/v1
  • API Key: sk-dummy (any non-empty string — backend doesn't validate)
  • TTS Model: tts-1
  • TTS Voice: {{ example_voice }} (any from voices list)
STT
  • Admin Panel → Settings → Audio → STT Engine: OpenAI
  • API Base URL: {{ public_base }}/api/v1
  • API Key: sk-dummy
  • STT Model: whisper-1 or whisper-large-v3-turbo-q4-1 — model name is forwarded to whisper-server and ignored, both work.
LLM (Chat completions)
  • Admin Panel → Settings → Connections → OpenAI API:
  • API Base URL: {{ llm_base }} (LAN: http://192.168.1.94:8080/v1)
  • API Key: sk-dummy
  • Available models: see GET /models test above{% if llm_models %} ({{ llm_models|length }} models){% endif %}
API Key auth: By default audio endpoints are public (no keys configured). To restrict access, create a key at API Keys and paste the sk-… value into OpenWebUI's API Key field. Once any key is created, all audio requests must supply Authorization: Bearer <key>.
